# Шрифты Apollo

Источник файлов: Daily.Story, `projects/frontend/src/common/assets/fonts`.
Файлы перенесены без изменения байтов; начертания и font-display сохранены
из `vite/early-fonts.plugin.ts`. Apollo не включает Vite-плагин приложения.

## Inter

InterVariable.woff2: variable 100–900, normal.
Лицензия SIL Open Font License 1.1 приложена в `Inter/LICENSE.txt`.
Официальный источник лицензии: https://github.com/rsms/inter/blob/master/LICENSE.txt

## Gilroy

Medium и Bold, WOFF2 + WOFF. В WOFF OS/2 веса — 500 и 700; для совместимости
с Daily.Story CSS регистрирует Medium как 400, Bold как 700.
Метаданные содержат copyright Radomir Tinkov и дополнительную строку
о сторонней перепаковке. Документов на использование и распространение
в исходном проекте нет. Условия распространения в публичном пакете не подтверждены.

Использование Apollo в собственных проектах определяет единые настройки
типографики, но само по себе не устанавливает права на распространение файлов.
Перед публичным выпуском уточнить права на Gilroy и при необходимости
заменить файлы на лицензированные. Текущий перенос предназначен для локальной проверки.
